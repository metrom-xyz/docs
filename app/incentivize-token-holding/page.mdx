## Incentivize token holding

A Hold token incentive campaign rewards wallets for holding a specific fungible 
token over a set duration.

### How it works

1. Select the Chain, token to incentivize and duration
- `Token address`: Paste the contract address of the token to incentivize.
- `Duration`: Pick duration for the campaign.

2. Define the rewards
- Add the reward tokens and amounts to be distributed over the campaign duration. 
 
3. Approve assets and launch
 - Review the campaign preview on the right panel, approve the reward tokens, and launch.
