## Restrictions

When creating a campaign on Metrom you can choose to add `restrictions`, to
either `Block` any address from receiving rewards, or `Allow` only
those that should be eligible to receive rewards.

To enable restrictions, expand ` Define rewards to distribute` and navigate to `Define 
who can earn rewards` section. Then, select the type of restriction and add addresses 
either manually or by importing a CSV file (the CSV must contain a single column listing 
the addresses). A maximum of 20 addresses can be blocked or allowed.
